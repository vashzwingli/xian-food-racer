# 结构与性能边界

`scripts/build.mjs` 将 JavaScript 和 CSS 注入模板，输出单文件。标准版保留固定 Three.js CDN 映射；离线版合并相同版本的 Three.js 及所用附加模块，不请求外网。

| 文件 | 职责 |
| --- | --- |
| `src/game.js` | 场景、城市、赛程、驾驶、碰撞、特效、HUD 和输入协调 |
| `src/content.js` | 西安街区名称与原创街头记忆 |
| `src/models/procedural.js` | 几何、材质、招牌和纹理缓存 |
| `src/models/player-car.js` | 跑车、轮胎、喷口、接地影和车身构造 |
| `src/models/cockpit.js` | 摄像机内的仪表、方向盘、雨刷及独立渲染层 |
| `src/models/bell-tower.js` | 三重檐钟楼、真实券洞与可开启木门；静态部分参与城市合批 |
| `src/engine/entrance.js` | 同一场景中的下降、穿门和回望镜头，与菜单共用最终机位 |
| `src/engine/road-index.js` | 空间格网索引与连续路段投影 |
| `src/engine/batching.js` | 合并静态零件，保留动画节点 |
| `src/engine/wheel-instances.js` | 交通车轮实例缓冲，保留各轮旋转 |
| `src/engine/performance.js` | 固定时间步、自动分辨率与效果档位 |
| `src/engine/handling.js` | 渐进转向、制动换向、动力、侧滑与抓地恢复 |
| `src/engine/speed-blur.js` | 速度/转向相关九采样单帧后期，中央和驾驶仪表保护 |
| `src/audio/synth-score.js` | 原创离线合成配乐 |
| `src/audio/local-track.js` | 音频导入、验证、IndexedDB、HTMLAudio 和 WebAudio 混音 |
| `src/template.html` / `src/styles.css` | 菜单、HUD、电台、触屏和适配 |
| `src/intro.js` / `src/intro-screen.html` / `src/intro.css` | 独立于 Three.js 加载的入场界面、真实准备阶段、跳过、重看与减少动态适配 |

未引入 UI 框架、远程音频下载或完整物理引擎；当前为街机驾驶和有向包围盒碰撞。城墙段和街区位置是游戏化设计。

入场控制器以普通内联脚本先执行，SVG/CSS 不依赖游戏模块或 CDN。引擎、灯光、程序化城市依次报告准备阶段；首帧真实渲染后才允许进度到100%和开门。底色与绘图独立淡出，露出同一场景中的三维钟楼；约6.1秒时间线控制下降、穿过实际圆券通道和回望，最终相机位置/目标与菜单完全相同。按实际绘制帧累计时间，每帧最多推进250ms；着色器编译或低帧率造成长帧时适当慢放，保证穿门可见。每16秒检查镜头进展，无进展时恢复菜单；正常缓慢推进不会被总时长截断。入场时仅每帧更新一次菜单氛围，避免模拟追赶增加负担，竞赛物理仍为60Hz固定步长。木门保留动态节点，不进入静态合批；挤出几何归一为有索引格式，避免与城市其他几何合并失败。

跳过仅缩短演出，不绕过准备。菜单在入场期间 inert，完成后把焦点交给发车按钮；重看复用几何，不重新加载世界或重启音乐。减少动态偏好省略三维镜头并停用装饰动画；模块加载或初始化失败显示重试，菜单保持锁定。`raceTest` 在首次入场完成后开放，旧赛程验收仍从可操作菜单开始。入场回归除正常/跳过/失败/适配外，还对真实渲染网格沿穿门路径射线检查，验证实际穿行帧和最终相机位置。

入场回归逐一比较重看前后几何、材质和纹理的资源身份。切换宽高比后，新的物体进入视野会首次上传到显卡，`renderer.info.memory` 可因此增加；这与重建场景或资源泄漏需要区分。重开回归另外在相同视角完成绘制后检查显卡资源回收。

确认首帧后，纯SVG加载画面完全遮住场景的时段暂停三维绘制，留出CPU/GPU绘制标题和描线；进入淡出/穿门阶段立即恢复。首帧准备检查、音频总线与跳过控制继续工作。

重看先取消旧CSS动画、刷新样式，再创建新的动画，避免提前跳过留下的延迟字形状态。正常入场等标题/美食印章的透明度达到完成状态，再经过两次动画帧后开始淡出；仅经过几秒实际时间不足以证明慢设备已显示完整标题。跳过和减少动态模式直接通过。

GitHub Pages 发布 `.pages/index.html`，内容与 `index.offline.html` 逐字节相同。构建与全部回归成功后才上传 Pages 产物，独立部署任务使用 Pages 写权限与 OIDC；没有发布密钥写入代码。

## 时间与质量

显示帧通过累加器执行 1/60 秒模拟，最多补八步；后台长停顿不累计，避免恢复时车辆跃迁。高速时再以约 0.38 米距离细分碰撞。测试验证 30 / 60 / 144 Hz 显示的五秒模拟均执行 300 步。

自动模式平滑帧耗时，持续超过阈值才降级，稳定更多采样后才恢复；忽略切后台等大停顿，并避开最初着色器编译。流畅档直接渲染主场景，其他档使用高阈值 Bloom。调整分辨率时同步更新渲染器和后期缓冲。

动态模糊通过 [Three.js ShaderPass](https://threejs.org/docs/pages/ShaderPass.html) 在色调映射之前处理场景颜色：随速度与转向生成有限的屏幕空间采样偏移，没有跨帧残影。它不是逐物体运动矢量重建。车体所在中央、驾驶室下方仪表与页面HUD不受模糊影响。V 设置保存在本机；静止、暂停、流畅档停用，减少动态偏好默认关闭。

驾驶采用固定步长下的渐进方向输入、速度相关转向、横向速度与抓地衰减；手刹放宽侧滑，落地后恢复普通抓地。S 在当前行驶方向上制动，停稳后等 0.22 秒才反向；退出火箭额外减速而不瞬间截断速度。实体前轮转向、车身俯仰响应同一驾驶状态。

三种视角共享73°视场角。驾驶视角从车内眼位观察，隐藏外车壳的渲染层，保留大灯及场景；内饰单独挂在摄像机上。翻滚时稳定地平线。追车镜头沿整个目标段查找碰撞候选并处理已进入屋檐的摄像机。

## 资源与实例

静态城市按材质和空间合并。交通车轮共享几何，以 InstancedMesh 提交；每个显示帧只更新一次实例矩阵。原轮胎网格保留层级变换并停止提交绘制。重建前释放旧实例缓冲及临时几何，招牌和共享几何保留复用。

街坊按实际屋檐/雨棚/厨具范围预留带间距的占地，预先保留地标、城门和城墙楼。创建模型后、合并之前记录每组真实几何的范围，回归检查模型范围是否相交或越出预留占地。楼体之外增加屋檐、雨棚、门柱与外机碰撞；远景楼也加入占地和碰撞。239处街坊模型范围均通过检查。该检查不等于宣称整座场景所有装饰表面都永不相交。

浏览器测试在相同相机位置等待渲染稳定，比较连续重开四次的纹理和几何计数。该计数及本机耗时不能外推成所有设备的帧率。

## 音乐与数据

内置《西安人的歌》现场版 MP3 经 esbuild dataurl loader 编入两种单文件；运行时不访问音乐平台。HTMLAudio 按需解码，与导入文件的对象 URL 共用一套 WebAudio 分析/混音总线。内置/本地/原创三种来源互斥，原创曲淡出；支持总静音、独立音量和删除导入后恢复内置。歌曲来源见 `assets/audio/SOURCE.md`。

场景首帧就绪后创建混音并尝试恢复AudioContext、播放当前来源。默认内置歌曲入场时直接起播；原创合成配乐仅在切换、保存的原创来源恢复或需要时才离线合成，减少首屏工作。使用实际播放承诺和AudioContext状态判断是否需要手势；限制播放时按钮明确显示“点击开启音乐”，一次真实点击重试。重看不重新触发自动播放，不覆盖用户本次关闭/静音选择。`tests/autoplay.cjs` 在隔离浏览器使用[Chrome官方开发测试参数](https://developer.chrome.com/blog/autoplay/)分别测试允许和受限策略，验证实际非零音频信号，没有向产品注入这些参数。

IndexedDB 只保存一份导入 Blob、歌名、音量和来源选择；内置歌曲不重复写入。没有音频上传或运行时跨源下载逻辑。更换、删除时释放旧对象 URL。切歌通过序号隔离异步播放结果，避免旧播放承诺暂停新曲。持久化不可用时本次仍能播放，并提示下次重新导入。不同页面地址的本机存储彼此独立。

来源和音量另同步写入轻量本机设置，刷新时优先于较慢的音频数据库记录，避免快速切歌后立刻刷新丢失选择。Blob 导入/删除保持异步，验收等待事务完成后再刷新；过期的初始化读取不会覆盖用户已执行的切歌。

## 验收

引擎测试覆盖道路查询、时间步和自适应策略；浏览器测试覆盖两种构建、电台、布局、触屏与资源回收；四个根目录 QA 覆盖赛道、城市、交通和操作。电台测试用运行时生成的两秒纯音。

完整正常入场、慢依赖跳过、重看、淡出和真实穿门由intro套件覆盖；自动音乐策略由autoplay套件在无手势状态独立验证。其他游戏操作套件通过真实鼠标点击“跳过入场”进入菜单，避免每次音乐导入刷新、驾驶场景都重复播放整段镜头。入场视觉探针在点击前安装，逐帧记录标题和淡出实际出现，避免截图耗时导致错过阶段。

`window.raceTest` 是单机验收接口，用于复现状态、道路射线采样和自动驾驶；没有多人排名或联网竞技。
